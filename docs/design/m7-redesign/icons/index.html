LabControl — action icon set (98 icons)

Drawn for LabControl on a 24×24 grid: 2 px stroke, round caps and joins, no fill — the Lucide convention, so a Lucide icon (ISC licence) can be added later without looking foreign. Each icon is one path geometry (no circles/rects), usable unchanged as Avalonia StreamGeometry and as an SKPath for the student overlay. Shown at 24 px and 16 px.
